# Conquer Academy

Proyecto multipágina para la quinta tarea entregable de CSS. Parte del proyecto realizado en el módulo de HTML y lo transforma en una experiencia visual completa, responsive y accesible.

## Características

- Maquetación mobile first con dos puntos de adaptación.
- Navegación responsive y accesible.
- Diseño común para inicio, cursos, blog, contacto, registro y acceso.
- Estados hover y focus visibles.
- Formularios de demostración con validación local.
- HTML semántico, imágenes adaptables e iconos SVG.

## Tecnologías

HTML5, CSS3 y JavaScript sin dependencias.
