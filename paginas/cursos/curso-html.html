Desarrollo web con HTML

Construye la estructura de sitios completos utilizando HTML semántico.

Descripción del curso

Este curso parte de cero y enseña a organizar información para que navegadores, buscadores y personas puedan interpretarla correctamente. Cada bloque combina una explicación breve con una práctica.

Al finalizar, habrás creado un sitio multipágina con navegación, contenido multimedia, tablas y formularios.

Qué aprenderás

  1. Estructura básica de un documento HTML.
  2. Encabezados, párrafos, listas y enlaces.
  3. Imágenes adaptables y contenido multimedia.
  4. Etiquetas semánticas y jerarquía de títulos.
  5. Formularios con distintos tipos de campos.
  6. Metadatos esenciales para buscadores.

Información práctica

Duración
8 semanas
Dedicación recomendada
6 horas por semana
Requisitos
No se necesita experiencia previa.
